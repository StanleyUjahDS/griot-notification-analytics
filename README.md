# Notification Delivery Analytics

A privacy-safe product-analytics project for measuring notification delivery
funnels: sent, received, displayed, and opened.

The repository generates a synthetic event dataset with the same type of
aggregate fields used in mobile notification reporting. No Griot user exports,
email addresses, device identifiers, or production secrets are included.

## Metrics

- Delivery rate: received / sent
- Display rate: displayed / received
- Open rate: opened / displayed
- End-to-end engagement: opened / sent

## Run locally

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m src.analytics
pytest
```

This project demonstrates product analytics and monitoring design; the values
generated by default are synthetic and should not be interpreted as Griot
production results.
